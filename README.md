# Shipper TMS Documentation

This repository contains user documentation for **Shipper TMS for Microsoft Dynamics 365 Business Central**.

Start with [index.md](index.md) or open the published help site: <https://stms.extensions-lab.com>.

## Authoring rules

- Write for planners, dispatchers, administrators, and integration users.
- Use short task-based sections: **Before you start**, **Steps**, **Verify**, **Troubleshooting**, **Related**.
- Use relative links such as `transportorder.md` and `resources/topic/file.png`.
- Keep screenshots in `resources/<topic>/`.
- Register every planned screenshot in [screenshot-registry.md](screenshot-registry.md).
